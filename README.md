# fabula

Gherkin BDD for Ada. fabula parses Gherkin feature files and runs them
against step definitions written in Ada. The core is built on
[sml-ada](https://github.com/ldm5180/sml-ada) state machines and is
SPARK-proven.

**Status: under construction — v1 in progress.**

## Build, test, prove

```sh
make build
make test
make prove
```
